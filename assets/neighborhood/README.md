# Neighborhood maple candidate

Source: Luminary Labs Low Poly Neighborhood free sample v0.1.0-rc1,
https://drive.google.com/file/d/1KKMhyBf2zE_oDkAywyX3rPaHNUb0-f7Q/view

Original studio-authored GLB, copied without geometry modifications. Runtime
normalizes its ground pivot and height to existing maple placements. The source
pack records Luminary Labs ownership and pending customer distribution terms;
this file is staged for internal game integration and visual review.

292 triangles, five opaque material batches. The three distance buckets reuse
the same small model shape; this is fixed geometry, not reduced LOD exports.
Existing World placement, instance capacity, and release lifecycle are retained.
Visual acceptance in the actual game remains open.
